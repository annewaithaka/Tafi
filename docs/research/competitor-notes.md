## Kenyan market (direct)

### UBUS — https://www.ubus.co.ke/ (FACT from site)
- **Who:** Kenyan schools; parents get WhatsApp notifications.
- **Workflow/patterns:** school signs up → "live in 24 hours" onboarding → parents get
  **one WhatsApp message, no app download** → link shows **live GPS + ETA + "arriving in N min"**.
- **Also offers:** school admin dashboard, driver mobile app, push notifications.
- **Pricing:** ~KES 100/student/month (public page), "no setup fee".
- **Trust signals:** Kenyan phone login, Kenya Data Protection Act 2019, EU data hosting.
- **Tafi relevance:** **closest match to Tafi's landing-page promise.** Strong evidence that
  "WhatsApp + no app download + live tracking" is the market expectation.

### Paaza — https://paaza.app/ (FACT from site)
- **Who:** schools / transport departments (operations-first).
- **Positioning:** "Stop managing school transport on spreadsheets and WhatsApp."
- **Patterns:** roster automation + manifests, ridership tracking, fleet management,
  digital trip requests + approvals, real-time parent alerts, billing.
- **Pain points it names:** manual logs, WhatsApp trip chaos, lost revenue, endless parent calls.
- **Tafi relevance:** validates the **operations-tool** angle Tafi's admin portal targets.

## Patterns worth adopting (INFERENCE)

1. **No app download for parents** — WhatsApp message + web link is the winning pattern.
2. **"Live in 24 hours" onboarding**, with school setup handled for them.
3. **Operations core first** (roster/manifests/fleet), parent visibility second.
4. **Per-student/month pricing** is the norm (~KES 100 in Kenya).
5. **Trust framing**: local phone login, data-protection compliance, data residency.

## Hypothesis to validate with the owner

If schools are the buyer and parents get value via WhatsApp links, the MVP should prove the
**school operations core** plus **one parent WhatsApp notification** — not a parent app or
live GPS in v1.
